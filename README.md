# edgelist

Edge color list values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/edgelist/

## Install / run

```bash
git clone https://github.com/theworker02/edgelist.git
cd edgelist
node src/cli.js
node --test
```
